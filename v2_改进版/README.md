# DSLite 烧录工具 v2 — 改进内容

## 与原版 (v1) 对比

| 改进点 | v1 原版 | v2 改进版 |
|--------|---------|-----------|
| **路径检测** | 硬编码 `C:\Users\hjs\Desktop\...` | 🔥 自动搜索 TI/CCS 安装目录 + 手动选择 |
| **配置持久化** | 无 | 🔥 自动保存/加载 `dslite_config.json` |
| **进度条** | 无 | 🔥 QProgressBar 显示执行进度 |
| **多线程安全** | 单线程变量 | 🔥 线程池管理，支持多任务 |
| **操作超时** | 无 | 🔥 120秒超时保护 |
| **日志导出** | 无 | 🔥 "保存日志" 按钮 + 自动滚动开关 |
| **内存预览** | 全量加载会卡死 | 🔥 仅显示前512字节，大文件友好 |
| **芯片选择** | 固定 F28034 | 🔥 下拉框支持 6 种芯片 |
| **UI 布局** | 垂直滚动太长 | 🔥 标签页 + 分栏布局 |
| **自动检测** | 无 | 🔥 一键搜索 DSLite + C2000 编译器 |
| **配置文件** | 无 | 🔥 保存窗口大小、最近文件路径等 |
| **版本标识** | 无 | 🔥 标题栏显示 v2.0 + 日期 |

## 文件说明

- `dslite_tool_v2.py` — 主程序（直接运行）
- `f28034.ccxml` — F28034 调试配置
- `dslite_config.json` — 自动生成的配置（保存窗口设置、路径等）

## 使用方式

```powershell
python dslite_tool_v2.py
```

或打包成 exe：
```powershell
pip install pyinstaller
pyinstaller --onefile --windowed dslite_tool_v2.py
```
